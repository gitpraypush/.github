## Welcome to GitPrayPush 🙏

We don't write bugs. We write *undocumented features* that require faith to resolve.

Here at GitPrayPush, our development methodology is simple and time-tested:

1. **Code** — usually at 2 AM, fueled by caffeine and misplaced confidence.
2. **Pray** — to whichever deity governs the CI/CD pipeline that day.
3. **Push** — directly to `main`, because staging is for cowards.
4. **Hope for the best** — and quietly refresh the deploy logs.

---

### Our Core Values

- ✅ **"It works on my machine"** is a valid QA sign-off.
- ✅ Test coverage is a *feeling*, not a number.
- ✅ Every `TODO` comment is a promise we fully intend to break.
- ✅ We read the documentation only after the outage.
- ✅ `git blame` is a team-building exercise.
